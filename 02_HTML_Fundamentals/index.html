The Basic Language of the web: HTML

All Modern websites and web applications are built using three fundamental technologies: HTML, CSS and JavaScript. These are the languages of the web.

In this post, let's focus on HTML. We will learn what HTML is all about, and why you too should learn it.

What is HTML?

HTML stands for HyperText Markup Language. It's a markup language the web developers use to structure and describe the content of a webpage (not a programing language).

HTML consists of elements that describe different types of content: paragraphs, links,heading, images, video, etc. Web browsers understand HTML and render HTML code as websites.

In HTML, each element is made up of 3 parts:

  1. The opening tag
  2. The closing tag
  3. The actual element

Why you should learn HTML?

There are countless reason for learning the fundamental language of the web. Here are 5 of them:

  • To be bale to use the fundamental web dev language
  • To hand-craft beautiful websites instead of relying on tools like Wordpress or Wix
  • To build web applications
  • To impress frieds
  • To have fun :D
